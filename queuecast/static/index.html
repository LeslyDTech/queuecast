QueueCast

Simulate a day at 86 real Walt Disney World and Universal Orlando rides, calibrated to their actual average posted waits. Test how crowds, priority-lane usage, and downtime change the line.

GitHub API

How it works

  1. Each ride's capacity is estimated from public descriptions of its ride system.
  2. Guest demand is calibrated so that, averaged over many simulated days, the ride's posted wait matches its real all-time average.
  3. Each run simulates one day: guests arrive, ride vehicles dispatch, and rides sometimes break down. Days vary, so try a few.
